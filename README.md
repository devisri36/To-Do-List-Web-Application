# To-Do List Application

To-Do List Application is a clean and responsive To-Do List web application built using React.js, JavaScript, HTML, and CSS.  
The application helps users organize daily tasks with features like task creation, editing, completion tracking, filtering, searching, sorting, archiving, and dark mode support.

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Archive completed tasks
- Task priority selection
  - High
  - Medium
  - Low
- Search tasks by title
- Filter tasks
  - All
  - Pending
  - Completed
- Sort tasks
- Responsive modern UI
- Dark/Light mode toggle
- Form validation
- In-memory task storage using arrays and React state

## How It Works

- Tasks are stored temporarily using JavaScript arrays and React state.
- No backend or database is used.
- Once the page is refreshed, tasks are cleared because data is stored only in memory.
